Política de Privacidade

Nós coletamos apenas as informações básicas fornecidas pelo usuário através da API da Meta (como ID de usuário, nome e e-mail) necessárias para a prestação dos serviços de marketing.

Como usamos os dados

Os dados são utilizados exclusivamente para gerenciar campanhas, identificar contas comerciais e facilitar a comunicação entre o sistema e as redes sociais integradas.

Compartilhamento e Segurança

Não compartilhamos, vendemos ou alugamos seus dados pessoais a terceiros. Implementamos medidas de segurança para proteger suas informações contra acesso não autorizado.

Exclusão de Dados

Você tem o direito de solicitar a exclusão de seus dados a qualquer momento. Para isso, envie um e-mail para rafael.abraovoz@gmail.com com o assunto "Solicitação de Exclusão de Dados". Após a sua solicitação, removeremos todas as informações associadas ao seu ID de usuário em nosso banco de dados em até 72 horas.
